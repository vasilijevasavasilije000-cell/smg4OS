# smg4OS Boot Splash & Splash Screen Configuration\n\n## Plymouth Boot Splash\n\nPlymouth is the boot splash screen manager for modern Linux distributions.\n\n### Installation\n\n```bash\nsudo apt install plymouth plymouth-themes\n```\n\n### Theme Configuration\n\n**File:** `config/branding/boot-splash/smg4-theme.plymouth`\n\n```\n[Plymouth Theme]\nName=smg4\nDescription=SMG4-Inspired Boot Theme\nModuleVersion=2\n\n[Plymouth Theme Entry Documents]\nResolutionDependent=no\nBackground=background.png\nProgressBar=progress-bar.png\nMessageFont=DejaVu Sans 12\nMessageColor=0xffffff\nProgressBar=progress-bar.png\n```\n\n### Boot Splash Assets\n\n```\nconfig/branding/boot-splash/\n├── smg4-theme.plymouth      # Theme configuration\n├── background.png           # Boot background (1920x1080)\n├── logo.png                # SMG4 logo (centered)\n├── progress-bar.png        # Loading bar animation frames\n├── spinner.png             # Loading spinner\n└── fonts/\n    └── DejaVuSans.ttf\n```\n\n### Colors\n\n- **Background:** `#000000` (Pure black)\n- **Progress bar:** `#FFD700` (Gold)\n- **Text:** `#FFFFFF` (White)\n- **Accent:** `#00AA00` (Retro green)\n\n### Boot Messages\n\n```\nStarting smg4OS...\nLoading kernel...\nInitializing filesystems...\nStarting system services...\nWelcome to smg4OS!\n```\n\n### Installation Steps\n\n1. **Copy theme files:**\n   ```bash\n   sudo cp -r config/branding/boot-splash/smg4 /usr/share/plymouth/themes/\n   ```\n\n2. **Set as default:**\n   ```bash\n   sudo update-alternatives --install /etc/plymouth/current.theme \\\n       plymouth.theme /usr/share/plymouth/themes/smg4/smg4.plymouth 100\n   ```\n\n3. **Update initramfs:**\n   ```bash\n   sudo update-initramfs -u\n   ```\n\n4. **Test:**\n   ```bash\n   sudo plymouthctl show-splash\n   ```\n\n## GRUB Splash Screen\n\n**See:** `config/themes/smg4/grub/`\n\n### GRUB Boot Menu\n\nFile: `config/grub.cfg`\n\n```bash\nset timeout=5\nset default=0\nset theme=/boot/grub/themes/smg4/theme.txt\n```\n\n### Custom Boot Messages\n\nIn kernel boot parameters:\n```\nlinux /boot/vmlinuz root=/dev/sda1 ro quiet splash \\\n  fbcon=rotate:1 logo.nologo vt.handoff=7\n```\n\n## Kernel Boot Parameters\n\n### For Splash Screen\n\n| Parameter | Effect |\n|-----------|--------|\n| `splash` | Show splash screen |\n| `quiet` | Suppress boot messages |\n| `loglevel=3` | Only show warnings/errors |\n| `vt.handoff=7` | Plymouth handoff to VT 7 |\n| `logo.nologo` | Disable default logo |\n\n### Example Boot Line\n\n```\nlinux /boot/vmlinuz root=/dev/sda1 ro quiet splash vt.handoff=7\n```\n\n## Loading Animation\n\n### Progress Bar\n\nDesign a smooth progress bar animation:\n\n```\nFrame 0: [━━━━━━━━━━] 0%\nFrame 1: [━━━━━━━━━━] 10%\nFrame 2: [━━━━━━━━━━] 20%\n...\nFrame 10: [━━━━━━━━━━] 100% ✓\n```\n\nFrames should be:\n- Smooth, continuous animation\n- 10-20 frames for smooth motion\n- 100-200ms per frame\n- Colors matching branding\n\n### Spinner Animation\n\nAlternative spinning animation:\n\n```\n◐ Loading...\n◓ Loading...\n◑ Loading...\n◒ Loading...\n```\n\nOr use animated rotation:\n```\n⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏\n```\n\n## Custom Boot Messages\n\n### File: `config/branding/boot-messages.txt`\n\n```\nStarting smg4OS...\n═══════════════════════════════════════════════════════════\n\n `config/branding/lightdm-greeter.conf`\n\n```ini\n[greeter]\nbackground=/usr/share/backgrounds/lightdm/smg4-login.png\nlogo=/usr/share/pixmaps/smg4-logo.png\nuser-background=false\nscroll-password=true\nshow-password-label=false\nshow-input-cursor=true\nfont-name=DejaVu Performance\n- Keep animation frames to minimum\n- Use efficient image formats (PNG, WebP)\n- Optimize file sizes\n- Hardware acceleration where possible\n\n### Accessibility\n- Sufficient color contrast\n- Large, readable text\n- Alternative text descriptions\n- No flashing (potential seizure risk)\n\n## Testing Boot Splash\n\n### Test Boot Messages\n```bash\n# Preview Plymouth theme\nsudo plymouthctl show-splash\n\n# Test with verbose output\nsudo plymouthctl show-message --text=\"Testing...\"\n\n# Quit Plymouth\nsudo plymouthctl quit\n```\n\n### Test GRUB Theme\n```bash\n# Regenerate GRUB config\nsudo grub-mkconfig -o /boot/grub/grub.cfg\n\n# Reboot to see theme\n# Press 'e' during boot to edit and add 'vga=ask' to test graphics modes\n```\n\n## File Locations\n\n```\nBoot Splash Files:\n  /usr/share/plymouth/themes/smg4/\n  /boot/grub/themes/smg4/\n  /usr/share/backgrounds/smg4/\n  /usr/share/pixmaps/smg4-logo.png\n\nConfiguration:\n  /etc/default/grub              (GRUB config)\n  /etc/plymouth/plymouthd.conf   (Plymouth config)\n  /etc/lightdm/lightdm.conf      (Login screen config)\n```\n\n## Creating Custom Splash Screens\n\n### Tools\n- **GIMP:** Full image
