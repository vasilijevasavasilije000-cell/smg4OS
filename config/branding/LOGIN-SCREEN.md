# smg4OS Login Screen & Lockscreen Configuration\n\n## LightDM Login Screen\n\nLightDM is the recommended login manager for smg4OS.\n\n### Installation\n\n```bash\nsudo apt install lightdm lightdm-gtk-greeter lightdm-gtk-greeter-settings\n```\n\n### Configuration File\n\n**File:** `/etc/lightdm/lightdm-gtk-greeter.conf`\n\n```ini\n[greeter]\n# Background image\nbackground=/usr/share/backgrounds/smg4/smg4-login-1920x1200.png\n\n# Logo displayed in the top-right\nlogo=/usr/share/pixmaps/smg4-logo-text.svg\n\n# Whether to show user background image instead of theme\nuser-background=false\n\n# Whether to show the panel\nshow-panel=true\npanel-position=top\n\n# Font\nfont-name=DejaVu Sans 12\ntext-color=#ffffff\n\n# Theme\ngtk-theme-name=Adwaita\nicon-theme-name=papirus\ncursor-theme-name=DMZ-White\n\n# Password entry\nscroll-password=true\nshow-password-label=false\nshow-input-cursor=true\ninactive-text-color=#999999\npassword-background-color=#2d2d2d\npassword-text-color=#ffffff\n\n# Session selection\nshow-session-selector=true\n\n# User selector\nuser-list-visibility=enabled\nallow-guest=false\n```\n\n### Lightdm Main Config\n\n**File:** `/etc/lightdm/lightdm.conf`\n\n```ini\n[General]\nstart-default-seat=true\nsession-wrapper=/etc/X11/Xsession\ngreeter-session=lightdm-gtk-greeter\ngreeter-hide-users=false\nallow-user-switching=true\nallow-guest=false\nlock-memory=true\nrun-user-session=true\n\n# Keyboard layout\nkeyboard-layout=us\n\n# Fallback settings\nfallback-session-name=XFCE\n```\n\n## Custom Lockscreen (i3lock)\n\nFor enhanced security and customization.\n\n### Installation\n\n```bash\nsudo apt install i3lock imagemagick\n```\n\n### Lockscreen Script\n\n**File:** `~/.local/bin/smg4-lock`\n\n```bash\n#!/bin/bash\n# smg4OS Lockscreen with custom image and blur effect\n\nLOCK_IMAGE=\"/usr/share/backgrounds/smg4/smg4-lockscreen-1920x1080.png\"\nDISPLAY_NUM=$(echo $DISPLAY | sed 's/^.*://g' | sed 's/[^0-9]//g')\n\n# Optional: Create blurred version of current screen\nif command -v convert &> /dev/null; then\n    # Blur screenshot and use as background\n    import -window root /tmp/screen.png\n    convert /tmp/screen.png -blur 0x8 /tmp/screen-blur.png\n    LOCK_IMAGE=\"/tmp/screen-blur.png\"\nfi\n\n# Lock screen with image\ni3lock -i \"$LOCK_IMAGE\" \\\n    -c 000000 \\\n    -e \\\n    -f \\\n    --insidevercolor=00000000 \\\n    --insidewrongcolor=FF634700 \\\n    --insidecolor=0d0d0d80 \\\n    --ringvercolor=FFD700ff \\\n    --ringwrongcolor=FF6347ff \\\n    --ringcolor=2d2d2dff \\\n    --separatorcolor=FFD70000 \\\n    --textcolor=FFFFFFff\n```\n\nMake executable:\n```bash\nchmod +x ~/.local/bin/smg4-lock\n```\n\n### Keyboard Shortcut\n\nAdd to XFCE keyboard settings or `~/.bashrc`:\n\n```bash\n# Add this to XFCE keyboard settings:\n# Command: ~/.local/bin/smg4-lock\n# Shortcut: Ctrl+Alt+L\n```\n\n## SDDM Login Manager (Alternative)\n\nKDE Plasma default, also available for other DEs.\n\n### `/etc/sddm.conf.d/kde_settings.conf`\n\n```ini\n[General]\nSession=plasmawayland\nLocale=en_US.UTF-8\n\n# Theme\nCursorTheme=breeze_cursors\nCursorSize=24\nFont=DejaVu Sans,10,-1,5,50,0,0,0,0,0\nLoginMode=Session\nSession=plasmawayland\nTheme=breeze\n\n# Face icon\nFaceIconsEnabled=true\n\n# Session (Alternative)\n\nFor Gnome-based setups.\n\n### Configuration\n\n```bash\n# Set lockscreen timeout (seconds)\ngsettings set org.gnome.desktop.session idle-delay 300\n\n# Disable unlock hints\ngsettings set org.gnome.desktop.lockdown show-login-warning false\n\n# Set background image\ngsettings set org.gnome.desktop.screensaver picture-uri 'file:///usr/share/backgrounds/smg4/smg4-lockscreen.png'\n```\n\n## Login/Lockscreen Assets\n\n### Required Files\n\n```\nconfig/branding/login-screen/\n├── lightdm-config/\n│   ├── lightdm.conf\n│   └── lightdm-gtk-greeter.conf\n├── images/\n│   ├── smg4-login-1920x1200.png       (Login background)\n│   └── smg4-lockscreen-1920x1080.png  (Lockscreen background)\n├── icons/\n│   ├── (White)\nAccent: #FFD700 (Gold)\nSecondary: #00AA00 (Green)\nError: #FF6347 (Red)\nInputBox: #2d2d2d (Dark gray)\n```\n\n## Design Specifications\n\n### Login Background Image\n\n- **Resolution:** 1920x1200px (common 16:10 ratio)\n- **Alternative:** 1920x1080px (16:9)\n- **Format:** PNG\n- **File Size:** < 5MB\n- **Content:** Login prompt area should be clear/dark\n\n### Design Considerations\n\n1. **Logo Placement**\n   - Top-right corner (logo setting)\n   - Or centered with username/password fields below\n\n2. **Text Readability**\n   - White text on dark background\n   - Sufficient contrast ratio (4.5:1 minimum)\n   - No text in the central area (reserved for login prompt)\n\n3. **Aesthetic**\n   - Dark, professional look\n   - SMG4 elements/colors (gold, green)\n   - Gaming/tech vibe\n   - Meme-friendly but professional\n\n## Customization Examples\n\n### Change Lock Timeout\n\n```bash\n# XFCE: Lock after 15 minutes of inactivity\nxfconf-query -c xfce4-power-manager -p /xfce4-power-manager/inactivity-sleep-time-ac -s 900\n```\n\n### Custom Login Sound\n\n```bash\n# Add startup sound to LightDM\n# Create script in /etc/lightdm/greeter-session-setup.d/\n#!/bin/bash\npaplay /usr/share/sounds/smg4/login.wav 2>/dev/null\n```\n\n### Adjust Login Prompt Position\n\nEdit XFCE theme to reposition login box:\n```css\n.login-dialog {\n    margin-top: 50px;  /* Push down from top */\n}\n```\n\n## Testing & Troubleshooting\n\n### Test LightDM\n\n```bash\n# Restart LightDM\nsudo systemctl restart lightdm\n\n# Or manually restart X session\n# Press Ctrl+Alt+F2, login, then:\nsudo systemctl restart lightdm\n```\n\n### Test Lockscreen\n\n```bash\n# Test i3lock\n~/.local/bin/smg4-lock\n\n# Or manual xlock\nxlock -background none -foreground none\n```\n\n### Check Logs\n\n```bash\n# LightDM logs\nsudo cat /var/log/lightdm/lightdm.log\nsudo cat /var/log/lightdm/x-0-greeter.log\n\n# X session logs\ncat ~/.local/share/xfce4/xfce4-session.verbose-log\n```\n\n## Security Considerations\n\n1. **Disable automatic login** in production\n2. **Enable password expiration** policies\n3. **Lock on suspend** (auto-lock in config)\n4. **Use strong password** validation\n5. **Two-factor authentication** (if supported)\n\n## Accessibility Features\n\n### High Contrast Mode\n\n```bash\ngsettings set
