system\nsudo cp -r config/themes/smg4 /usr/share/themes/\n\n# Set theme in XFCE Settings Manager\nSettings Manager → Appearance → Style/Icons\n```\n\n### For Boot\n\n```bash\n# Copy GRUB theme\nsudo cp -r config/themes/smg4/grub /boot/grub/themes/smg4\n\n# Update GRUB config\nsudo grub-mkconfig -o /boot/grub/grub.cfg\n```\n\n### For Login Screen\n\n```bash\n# Copy wallpapers\nsudo cp config/branding/images/*.png /usr/share/backgrounds/smg4/\n\n# Update LightDM config\nsudo cp config/branding/login-screen/lightdm.conf /etc/lightdm/\nsudo systemctl restart lightdm\n```\n\n## File Locations\n\n### User-Facing Assets\n```\n/usr/share/pixmaps/              # Application icons\n/usr/share/icons/                # Icon themes\n/usr/share/themes/               # Desktop themes\n/usr/share/backgrounds/          # Wallpapers\n~/.local/share/icons/            # User custom icons\n~/.config/                        # User configurations\n```\n\n### System Assets\n```\n/boot/grub/themes/               # GRUB themes\n/usr/share/plymouth/themes/      # Boot splash themes\n/etc/lightdm/                     # Login manager config\n```\n\n## Creating New Assets\n\n### Design Workflow\n\n1. **Concept**\n   - Reference branding guidelines\n   - Check color palette\n   - Review existing assets for consistency\n\n2. **Design**\n   - Create in vector format (SVG) when possible\n   - Use smg4OS color palette\n   - Follow typography rules\n   - Maintain consistent style\n\n3. **Export**\n   - PNG for raster assets (24-bit or 32-bit with alpha)\n   - SVG for logos and icons\n   - Multiple resolutions for responsiveness\n\n4. **Testing**\n   - Test on light and dark backgrounds\n   - Verify readability and contrast\n   - Check at different sizes\n   - Get community feedback\n\n5. **Integration**\n   - Place in appropriate directory\n   - Update documentation\n   - Create pull request\n   - Get approval from maintainers\n\n### Asset Creation Tools\n\n**Vector Graphics:**\n- Inkscape (free, open source)\n- Adobe Illustrator (commercial)\n\n**Raster Graphics:**\n- GIMP (free, open source)\n- Krita (free, open source)\n- Adobe Photoshop (commercial)\n\n**3D/Animation:**\n- Blender (free, open source)\n- Adobe After Effects (commercial)\n\n## Brand Voice & Messaging\n\n### Core Values\n- **Accessible** - Easy to use for everyone\n-
