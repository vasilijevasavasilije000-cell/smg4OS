# smg4OS Branding Guidelines\n\nThis document outlines the official branding standards for smg4OS.\n\n## Logo & Identity\n\n### Official Name\n**smg4OS** - The SMG4-Inspired Linux Distribution\n\n### Logo Variations\n- Full logo with text: For headers, primary branding\n- Icon only: For taskbars, favicons, small spaces\n- Wordmark: Text-based version for accessibility\n\n### Logo Files\n```\nconfig/branding/\n├── logo-full.svg         (Full logo with text)\n├── logo-icon.svg         (Icon only)\n├── logo-wordmark.svg     (Text only)\n├── favicon.ico           (Website favicon)\n└── logo-README.md        (Logo usage guide)\n```\n\n## Color Palette\n\n### Primary Colors\n\n| Name | Hex | RGB | Use |\n|------|-----|-----|-----|\n| Gold | #FFD700 | 255, 215, 0 | Primary accent, highlights |\n| Black | #000000 | 0, 0, 0 | Background, text |\n| White | #FFFFFF | 255, 255, 255 | Foreground text |\n\n### Secondary Colors\n\n| Name | Hex | RGB | Use |\n|------|-----|-----|-----|\n| Retro Green | #00AA00 | 0, 170, 0 | Gaming accent |\n| Tomato Red | #FF6347 | 255, 99, 71 | Alerts, errors |\n| Steel Blue | #4682B4 | 70, 130, 180 | Links, info |\n\n### Accent Colors\n\n| Name | Hex | RGB | Use |\n|------|-----|-----|-----|\n| Lime | #00FF00 | 0, 255, 0 | Success, positive |\n| Orange | #FFA500 | 255, 165, 0 | Warnings |\n| Purple | #9932CC | 153, 50, 204 | Features, special |\n\n## Typography\n\n### Official Fonts\n\n1. **Sans-serif (UI):** DejaVu Sans, Liberation Sans\n2. **Monospace (Code):** DejaVu Sans Mono, Courier New\n3. **Display (Headers):** DejaVu Sans Bold\n\n### Font Sizes\n\n- **Headlines:** 24-32pt, Bold\n- **Subheadings:** 16-20pt, Bold\n- **Body text:** 10-12pt, Regular\n- **Small text:** 8-10pt, Regular\n\n### Text Colors\n\n- **Primary text:** #FFFFFF (on dark backgrounds)\n- **Secondary text:** #CCCCCC\n- **Disabled text:** #666666\n- **Links:** #4682B4 (or #FFD700 on dark bg)\n\n## Imagery Style\n\n### Visual Language\n- Modern, clean, professional\n- Gaming/tech aesthetic\n- Meme-friendly but not unprofessional\n- Vibrant colors with dark backgrounds\n- Unicode/ASCII art for borders/dividers\n\n### Photography Guidelines\n- High contrast\n- Modern hardware/gaming peripherals\n- Linux/open source community vibes\n- Avoid stereotypes\n\n### Icon Style\n- Flat or minimal 3D\n- Clear, recognizable at small sizes\n- Consistent stroke weight\n- Aligned to pixel grid when rasterized\n\n## Logo Usage Rules\n\n### DO ✓\n- Use official logo files\n- Maintain clear space (1/4 of logo height minimum)\n- Scale proportionally\n- Use appropriate color variants\n- Include ® or ™ in attribution\n\n### DON'T ✗\n- Distort or skew the logo\n- Rotate the logo\n- Change colors without approval\n- Use low-resolution versions\n- Crowd the logo with other elements\n- Use outdated logo versions\n\n## Clear Space\n\nMaintain minimum clear space around logo:\n```\n  ┌──────────────────┐\n  │  CLEAR SPACE     │\n  │  ┌────────────┐  │\n  │  │  smg4OS    │  │  Min: 1/4 of logo height\n  │  │   LOGO     │  │\n  │  └────────────┘  │\n  │  CLEAR SPACE     │\n  └──────────────────┘\n```\n\n## Brand Voice & Tone\n\n### Characteristics\n- **Approachable:** Friendly, not stuffy\n- **Knowledgeable:** Technical but explainable\n- **Fun:** Memes and humor welcome\n- **Inclusive:** Welcoming to all skill levels\n- **Professional:** But with personality\n\n### Example Taglines\n- \"Making Linux fun again\"\n- \"The distro powered by memes\"\n- \"Where gaming meets open source\"\n- \"Professional chaos\"\n- \"Glitchy? No, that's a feature\"\n\n## File Formats & Specifications\n\n### Recommended Formats\n\n**Vector (Logos, Icons):**\n- SVG (Scalable Vector Graphics)\n- PDF (for print)\n\n**Raster (Photos, Complex Graphics):**\n- PNG (transparency support)\n- JPEG (photographs only)\n- WebP (web optimization)\n\n### Resolution Guidelines\n\n| Use Case | Resolution | Format |\n|----------|-----------|--------|\n| Logo (web) | 1024x1024px | SVG + PNG |\n| Favicon | 16x16, 32x32, 64x64 | ICO |\n| Wallpaper | 1920x1080, 2560x1440 | PNG |\n| Social media | 1200x630px | PNG/JPG |\n| Print | 300 DPI | PDF/SVG |\n\n## Social Media Guidelines\n\n### Profile Images\n- Logo icon (1:1 square)\n- Size: 400x400px minimum\n- Format: PNG with transparency\n\n### Cover Photos\n- Aspect ratio: 16:9\n- Size: 1200x630px (Twitter), 1500x500px (Facebook)\n- Feature logo and key visuals\n\n### Post Templates\n- Use brand colors consistently\n- Include logo in corner\n- Maintain readable text size\n- Leave white space\n\n## Documentation Branding\n\n### README Headers\n```markdown\n# smg4OS - [Project Name]\n[![smg4OS](logo-badge.svg)](https://github.com/smg4OS)\n```\n\n### License Headers\n```python\n# smg4OS Project\n# Licensed under GNU GPLv3\n# Made with ❤️ and powered by memes\n```\n\n## Brand Assets\n\nAll brand assets available in:\n```\nconfig/branding/\n├── logo-full.svg\n├── logo-icon.svg\n├── favicon.ico\n├── color-palette.json\n├── fonts/\n├── mockups/\n└── templates/\n```\n\n## Approval Process\n\nFor new branding materials:\n1.
