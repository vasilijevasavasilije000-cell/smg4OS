# smg4OS GRUB2 Theme Graphics\n\n## Background Image\n\n**File:** `background.png`  \n**Format:** PNG  \n**Resolution:** 1024x768px (minimum), 1920x1080px (recommended)  \n**Color Scheme:** SMG4-inspired (vibrant, meme-worthy)\n\n### Suggested Design Elements\n- SMG4 character silhouettes\n- Gaming/tech aesthetic\n- Dark background with bright accents\n- Unicode or pixel art borders\n- Boot message banner area\n\n### Color Palette\n- Primary: `#FFD700` (Gold) - Accent color\n- Secondary: `#00AA00` (Green) - Retro gaming feel\n- Background: `#000000` (Black) - Clean, professional\n- Text: `#FFFFFF` (White) - High contrast\n- Highlight: `#FF6347` (Tomato Red) - Alternative accent\n\n## Font\n\n**Font File:** `dejavu-sans-12.pf2`  \n**Source:** DejaVu Sans (standard Linux font)  \n**Size:** 12pt\n\nTo generate custom GRUB fonts:\n```bash\ngrub-mkfont -o custom.pf2 /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf\n```\n\n## Installation\n\nPlace files in:\n```\n/boot/grub/themes/smg4/\n├── theme.txt\n├── background.png\n└── fonts/\n    └── dejavu-sans-12.pf2\n```\n\n## Enable Theme\n\nIn `/etc/default/grub`:\n```bash\nGRUB_THEME=\"/boot/grub/themes/smg4/theme.txt\"\n```\n\nThen regenerate:\n```bash\nsudo grub-mkconfig -o /boot/grub/grub.cfg\n```\n"
