# smg4OS Wallpapers\n\nThis directory contains wallpapers for smg4OS desktop environments.\n\n## Recommended Wallpapers\n\n### Desktop Background\n\n**File:** `smg4-desktop-1920x1080.png`  \n**Resolution:** 1920x1080px  \n**Format:** PNG  \n**Color Scheme:** Dark background with SMG4 elements  \n**Style:** Modern gaming aesthetic with meme flair\n\n### Login Screen\n\n**File:** `smg4-login-1920x1200.png`  \n**Resolution:** 1920x1200px  \n**Format:** PNG  \n**Style:** Professional but fun\n\n### Lock Screen\n\n**File:** `smg4-lockscreen-1920x1080.png`  \n**Resolution:** 1920x1080px  \n**Format:** PNG  \n**Style:** Dynamic, eye-catching\n\n## Design Guidelines\n\n### Color Palette\n- Primary Gold: `#FFD700` - SMG4 signature color\n- Accent Green: `#00AA00` - Retro gaming feel\n- Background Black: `#000000` - Clean, modern\n- Text White: `#FFFFFF` - Maximum contrast\n- Alternative Red: `#FF6347` - Energy/excitement\n\n### Design Elements\n- SMG4 character artwork (if available)\n- Gaming/tech elements\n- Glitch art aesthetic (optional)\n- Unicode/ASCII art borders\n- Meme-friendly callouts\n\n### File Requirements\n- Format: PNG (lossless, transparent backgrounds supported)\n- Minimum Resolution: 1366x768px\n- Maximum File Size: 10MB per image\n- Color Space: sRGB\n\n## Installation\n\n### XFCE Desktop\n\n1. Copy wallpapers to system directory:\n   ```bash\n   sudo cp smg4-desktop-*.png /usr/share/backgrounds/xfce/\n   ```\n\n2. Set in XFCE settings:\n   - Right-click desktop\n   - Select \"Desktop\" → \"Background\"\n   - Choose wallpaper from list\n\n### Lightdm Login Screen\n\n1. Copy login wallpaper:\n   ```bash\n   sudo cp smg4-login-*.png /usr/share/backgrounds/lightdm/\n   ```\n\n2. Configure in `/etc/lightdm/lightdm-gtk-greeter.conf`:\n   ```ini\n   background=/usr/share/backgrounds/lightdm/smg4-login-1920x1200.png\n   ```\n\n### Lock Screen\n\n1. Install i3lock or similar:\n   ```bash\n   sudo apt install i3lock\n   ```\n\n2. Set as default locker with image:\n   ```bash\n   i3lock -i /usr/share/backgrounds/lockscreen/smg4-lockscreen.png\n   ```\n\n## Creating Custom Wallpapers\n\n### Tools Recommended\n- GIMP: Full-featured image editor\n- Krita: Digital painting\n- Inkscape: Vector graphics\n- ImageMagick: Command-line processing\n\n### Quick Generation with ImageMagick\n\n```bash\n# Create a dark background with text\nconvert -size 1920x1080 xc:#000000 \\\n  -pointsize 72 -fill '#FFD700' \\\n  -gravity center -annotate +0+0 'smg4OS' \\\n  smg4-wallpaper.png\n```\n\n## Contributing Wallpapers\n\nWe'd love community wallpaper contributions!
