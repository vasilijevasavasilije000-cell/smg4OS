# smg4OS Icon Theme\n\nThis directory contains custom icon configurations for smg4OS.\n\n## Icon Theme Options\n\n### Recommended Icon Packs\n1. **Papirus** - Modern, colorful, comprehensive\n2. **Numix Circle** - Clean, flat, circular icons\n3. **Adwaita** - GNOME default, consistent\n4. **Tango** - Classic, well-established\n\n## SMG4-Themed Icon Customizations\n\n### Color Modifications\n\nModify icon colors to use smg4OS palette:\n- Primary: `#FFD700` (Gold)\n- Secondary: `#00AA00` (Green)\n- Accent: `#FF6347` (Red)\n- Background: `#000000` (Black)\n\n### Custom Icons\n\nCreate custom icons for:\n- smg4OS folder icon\n- Application launcher icon\n- System tray icons\n- File type icons (themed)\n\n## Installation\n\n### Install System Icon Packs\n\n```bash\n# Papirus icons\nsudo apt install papirus-icon-theme\n\n# Numix Circle\nsudo apt install numix-icon-theme-circle\n\n# Additional options\nsudo apt install adwaita-icon-theme\nsudo apt install tango-icon-theme\n```\n\n### Set Icon Theme in XFCE\n\n1. Settings Manager → Appearance → Icons\n2. Select preferred icon theme\n3. Restart for changes to take effect\n\n### Create Custom Icon Links\n\nFor smg4OS-specific branding:\n\n```bash\n# Create custom icon directory\nmkdir -p ~/.local/share/icons/smg4\n\n# Copy and modify base icons\ncp -r /usr/share/icons/papirus ~/.local/share/icons/smg4\n\n# Edit colors in SVG files (if using vector icons)\nsed -i 's/#5294E2/#FFD700/g' ~/.local/share/icons/smg4/*/apps/*.svg\n```\n\n## Creating Custom Icons\n\n### Tools\n- **Inkscape** - Vector icon creation\n- **GIMP** - Raster icon editing\n- **Icon Fonts** - FontAwesome, Material Design Icons\n\n### Icon Specifications\n- Sizes: 16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256\n- Format: PNG (raster) or SVG (vector)\n- Transparency: Yes\n- Color Space: sRGB\n\n### Naming Convention\n\nFollow freedesktop icon naming standards:\n```\n~/.local/share/icons/smg4/scalable/apps/application-name.svg\n~/.local/share/icons/smg4/24x24/apps/application-name.png\n```\n\n## Configuration Files\n\n### index.theme\n\nCreate theme metadata file:\n\n```ini\n[Icon Theme]\nName=smg4\nComment=SMG4-Inspired Icon Theme\nDirectories=scalable/apps,scalable/actions,24x24/apps,48x48/apps\nInherits=papirus\n\n[scalable/apps]\nSize=128\nType=Scalable\n\n[24x24/apps]\nSize=24\nType=Fixed\n\n[48x48/apps]\nSize=48\nType=Fixed\n```\n\n## Icon Customization Scripts\n\n### Color Replace Script\n\n```bash\n#!/bin/bash\n# Replace colors in icon theme\n\nINPUT_DIR=\"$1\"\nOLD_COLOR=\"$2\"\nNEW_COLOR=\"$3\"\n\nfind \"$INPUT_DIR\" -name \"*.svg\" | while read file; do\n    sed -i \"s/$OLD_COLOR/$NEW_COLOR/g\" \"$file\"\n    echo \"Updated: $file\"\ndone\n```\n\nUsage:\n```bash\n./color-icons.sh ~/.local/share/icons/smg4 \"#5294E2\" \"#FFD700\"\n```\n\n## SMG4 Character Icons (Optional)\n\nCreate custom icons featuring SMG4 characters:\n- **File Manager:** Mario-themed folder\n- **Terminal:** Green pixel art terminal\n- **Browser:** Game controller icon\n- **Settings:** Gear with gold accent\n- **System:** SMG4 character/logo\n\n## Contributing Icons\n\nSubmit custom icon designs via pull request:\n- Original artwork preferred\n- Multiple sizes provided\n- SVG format for scalability\n- Follows smg4OS color palette\n- Proper attribution/licensing\n\n## Resources\n\n- [Freedesktop Icon Spec](https://specifications.freedesktop.org/icon-spec/)\n- [Papirus Project](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme)\n- [Icon Design Best Practices](https://wiki.gnome.org/Design/HIG/IconsandArtwork)\n"
