# smg4OS Setup Assistant Configuration\n\n## Overview\n\nThe smg4 setup assistant is an interactive installation wizard featuring SMG4's personality and humor while guiding users through system configuration.\n\n## Features\n\n- **Full System Setup** - Complete configuration from hostname to packages\n- **Desktop Theming** - Apply smg4OS themes, icons, and wallpapers\n- **Boot Customization** - Configure GRUB, Plymouth, and boot messages\n- **Development Setup** - Set up programming languages and dev tools\n- **Quick Setup** - Fast configuration for impatient users\n- **System Information** - Display hardware and software details\n\n## Usage\n\n```bash\n# Run main setup\n./setup-wizard/smg4-setup.sh\n\n# Or run individual scripts\n./setup-wizard/scripts/full-setup.sh\n./setup-wizard/scripts/theme-setup.sh\n./setup-wizard/scripts/boot-setup.sh\n./setup-wizard/scripts/dev-setup.sh\n./setup-wizard/scripts/quick-setup.sh\n./setup-wizard/scripts/system-info.sh\n```\n\n## Configuration Files\n\nStore configuration presets in `setup-wizard/config/` for quick deployment:\n\n```\nconfig/\n├── presets/\n│   ├── gamer.conf           # Gaming-focused setup\n│   ├── developer.conf       # Developer setup\n│   ├── minimal.conf         # Minimal installation\n│   └── full.conf            # Full installation\n└── templates/\n    └── system.conf          # Configuration template\n```\n\n## SMG4 Personality\n\nThe assistant includes:\n- Personalized messages from SMG4\n- Humor and memes throughout\n- Encouragement for good choices\n- Warning messages for important decisions\n- Success confirmations\n- Random jokes between setup steps\n\n## Extending the Wizard\n\nTo add new setup options:\n\n1. Create new script in `setup-wizard/scripts/`\n2. Source `colors.sh` for consistent styling\n3. Use `smg4_say()`, `smg4_success()`, etc. for messages\n4. Add option to main `smg4-setup.sh` menu\n\n## Variables\n\nCommon variables set during setup:\n\n```bash\nhostname          # System hostname\nusername          # Primary user account\nde                # Desktop environment\ntheme             # GTK/desktop theme\nicons             # Icon theme\nwallpaper         # Desktop wallpaper\ngrub              # GRUB theme\nsplash            # Boot splash theme\nlanguages         # Programming languages\ndev_tools         # Development tools\npackages_type     # Package category\n```\n\n## Color Codes\n\nDefined in `scripts/colors.sh`:\n\n- `$GOLD` - SMG4's signature color (#FFD700)\n- `$CYAN` - Regular text\n- `$GREEN` - Success messages\n- `$RED` - Errors and warnings\n- `$BLUE` - Sections and headers\n- `$YELLOW` - Important warnings\n- `$MAGENTA` - Special info\n- `$WHITE` - Important text\n\n## Future Enhancements\n\n- [ ] Configuration file support for unattended setup\n- [ ] Remote installation profiles\n- [ ] Post-setup optimization tips\n- [ ] System backup before major changes\n- [ ] Rollback functionality\n- [ ] Interactive package manager\n- [ ] Performance tuning wizard\n- [ ] Gaming optimization options\n"
