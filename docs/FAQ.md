# smg4OS FAQ\n\n## General Questions\n\n### What is smg4OS?\n\nsmg4OS is a lightweight Linux distribution inspired by SMG4 (SuperMarioGlitchy4), designed to be fun, creative, and user-friendly.\n\n### Who created smg4OS?\n\nsmg4OS is a community project. See [CONTRIBUTING.md](../CONTRIBUTING.md) to get involved!\n\n### What's the system philosophy?\n\n- Lightweight and fast\n- User-friendly\n- Community-driven\n- Customizable\n- Fun! 🎮\n\n## Installation & Setup\n\n### How do I install smg4OS?\n\n1. Download the latest ISO from releases\n2. Write to USB: `dd if=smg4OS.iso of=/dev/sdX bs=4M`\n3. Boot from USB\n4. Follow installer prompts\n\n### What are minimum requirements?\n\n- 2GB RAM\n- 10GB disk space\n- 1GHz processor\n- x86_64 architecture\n\n### Can I run it in a virtual machine?\n\nYes! Tested on:\n- QEMU/KVM\n- VirtualBox\n- VMware\n- Hyper-V\n\n### Do you support UEFI?\n\nYes, UEFI boot is fully supported. BIOS boot is also available.\n\n## Building\n\n### How do I build smg4OS from source?\n\nSee [BUILDING.md](BUILDING.md) for complete instructions.\n\n### What if the build fails?\n\n1. Check build.log\n2. Ensure all prerequisites are installed\n3. Try `./scripts/clean.sh` then rebuild\n4. Open an issue if problems persist\n\n### How long does a build take?\n\nTypically 30-60 minutes depending on hardware. Parallel builds with `-j` flag can speed this up.\n\n## Usage\n\n### How do I install packages?\n\n```bash\nsudo apt install package-name\n```\n\n### What desktop environment is used?\n\nDefault is XFCE. You can change to Openbox or minimal setup. See [CUSTOMIZATION.md](CUSTOMIZATION.md).\n\n### How do I update the system?\n\n```bash\nsudo apt update\nsudo apt upgrade\n```\n\n### How do I change the hostname?\n\n```bash\nsudo hostnamectl set-hostname new-hostname\n```\n\n## Performance\n\n### Is it faster than other distros?\n\nsmg4OS is optimized for speed and uses minimal resources. You'll likely see good performance on older hardware.\n\n### How much RAM does it use?\n\nMinimal install uses ~100-150MB. With desktop environment, ~200-300MB.\n\n### Can I disable the desktop?\n\nYes, run in minimal mode or disable graphical target:\n```bash\nsudo systemctl set-default multi-user.target\n```\n\n## Customization\n\n### Can I customize the theme?\n\nYes! See [CUSTOMIZATION.md](CUSTOMIZATION.md) for theming options.\n\n### Can I customize the kernel?\n\nYes! See [CUSTOMIZATION.md](CUSTOMIZATION.md) kernel section.\n\n### Can I use different DE?\n\nYes, you can install any DE that works on Linux:\n- KDE Plasma\n- GNOME\n- Cinnamon\n- etc.\n\n## Troubleshooting\n\n### Boot fails with \"No such file or directory\"\n\nYour initramfs may be corrupted:\n```bash\nsudo dracut -f\nsudo grub-mkconfig -o /boot/grub/grub.cfg\n```\n\n### System is slow\n\n- Check disk space: `df -h`\n- Check memory: `free -h`\n- Check load: `uptime`\n- Check processes: `top`\n\n### Can't connect to network\n\n```bash\n# List interfaces\nip link show\n\n# Enable interface\nsudo ip link set eth0 up\n\n# Get DHCP address\nsudo dhclient eth0\n```\n\n### Graphics not working\n\nTry:\n1. Install graphics drivers\n2. Disable graphics drivers: add `nomodeset` to boot parameters\n3. Update kernel\n\n## Contributing\n\n### How do I contribute?\n\nSee [CONTRIBUTING.md](../CONTRIBUTING.md)\n\n### How do I report bugs?\n\nOpen an issue with:\n- Clear title\n- Steps to reproduce\n- Expected vs actual behavior\n- System info\n\n### Can I request features?\n\nYes! Open an issue with the `enhancement` label and describe your idea.\n\n## License\n\n### What license is smg4OS under?\n\nGNU General Public License v3. You must share modifications.\n\n## Technical\n\n### What kernel version does it use?\n\nLatest stable LTS kernel (usually 5.x or 6.x)\n\n### What package manager?\n\nAPT-based (same as Debian/Ubuntu)\n\n### What init system?\n\nsystemd\n\n### Can I use proprietary software?\n\nYes, but smg4OS focuses on open source. Some proprietary drivers/software may need manual installation.\n\n## Getting Help\n\n### Where do I get support?\n\n1. Check this FAQ\n2. Join community discussions\n\n### Is there a wiki?\n\nYes, community members maintain a wiki with tips and tricks!\n\n## Still Have Questions?\n\nOpen an issue on GitHub or join community discussions.
