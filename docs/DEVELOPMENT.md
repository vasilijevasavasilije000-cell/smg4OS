# smg4OS Development Guide\n\nWelcome to smg4OS development! This guide covers everything you need to contribute.\n\n## Development Workflow\n\n### 1. Setup Development Environment\n\n```bash\ngit clone https://github.com/vasilijevasavasilije000-cell/smg4OS.git\ncd smg4OS\n./scripts/setup-dev.sh\n```\n\n### 2. Project Structure\n\n```\nsmg4OS/\n├── src/\n│   ├── kernel/           # Kernel patches and config\n│   ├── bootloader/       # GRUB configuration\n│   └── filesystem/       # Root filesystem structure\n├── config/\n│   ├── grub.cfg         # Bootloader config\n│   ├── kernel.config    # Kernel configuration\n│   └── fstab            # Filesystem table\n├── packages/\n│   ├── base.list        # Core packages\n│   ├── desktop.list     # Desktop packages\n│   └── gaming.list      # Gaming packages\n├── scripts/\n│   ├── build.sh         # Main build script\n│   ├── create-iso.sh    # ISO creation\n│   └── clean.sh         # Cleanup\n└── docs/                # Documentation\n```\n\n## Building\n\n### Quick Build\n\n```bash\n./scripts/build-all.sh\n```\n\n### Incremental Build\n\n```bash\n# Only rebuild kernel\n./scripts/build.sh kernel\n\n# Only rebuild userspace\n./scripts/build.sh userspace\n\n# Only create ISO\n./scripts/create-iso.sh\n```\n\n## Kernel Development\n\n### Apply Patches\n\n```bash\ncd src/kernel\ngit apply patches/*.patch\n```\n\n### Configure Kernel\n\n```bash\n./scripts/configure-kernel.sh\nmenuconfig  # Interactive configuration\n```\n\n### Build Custom Kernel\n\n```bash\ncd build/linux\nmake menuconfig\nmake -j$(nproc)\nmake modules_install\n```\n\n## Package Management\n\n### Adding Packages\n\n1. Edit `packages/base.list` or relevant list\n2. Add package name (one per line)\n3. Run `./scripts/build.sh packages`\n\n### Creating Custom Packages\n\nSee [Package Guide](PACKAGES.md)\n\n## Testing\n\n### Run Tests\n\n```bash\n./scripts/test.sh\n```\n\n### Test in VM\n\n```bash\nqemu-system-x86_64 \\\n    -cdrom iso/smg4OS-latest.iso \\\n    -m 2G \\\n    -smp 2 \\\n    -enable-kvm \\\n    -net user \\\n    -net nic\n```\n\n### Boot Testing\n\nTest different boot scenarios:\n- BIOS boot\n- UEFI boot\n- Secure Boot\n\n## Debugging\n\n### Enable Debug Output\n\n```bash\nSMG4OS_DEBUG=1 ./scripts/build.sh\n```\n\n### Kernel Debugging\n\n```bash\n# Add debug info to kernel config\necho \"CONFIG_DEBUG_INFO=y\" >> config/kernel.config\n./scripts/build.sh kernel\n```\n\n### Serial Console\n\n```bash\n# Add to kernel boot parameters\nappend=\"console=ttyS0,115200\"\n```\n\n## Code Style\n\n- Shell scripts: Use `shellcheck` for linting\n- Comments: Clear and concise\n- Commits: Descriptive messages with type prefix\n\n### Commit Message Format\n\n```\n[Add|Fix|Docs|Style|Refactor|Remove]: Brief description\n\nDetailed explanation if needed.\n\nRelates to #123\n```\n\n## Performance Optimization\n\n### Kernel Options\n\n- Enable CPU frequency scaling\n- Enable CFS scheduler\n- Optimize memory management\n- Tune I/O scheduler\n\n### Userspace Optimization\n\n- Strip binaries\n- Remove unused dependencies\n- Use static linking where appropriate\n- Compress filesystem\n\n## CI/CD\n\nBuilds are automated on push. See `.github/workflows/` for CI configuration.\n\n## Documentation\n\nUpdate docs when making changes:\n- BUILDING.md for build procedure changes\n- ARCHITECTURE.md for design changes\n- README.md for feature additions\n\n## Getting Help\n\n- Check existing issues\n- Ask in discussions\n- Read kernel documentation: https://www.kernel.org/doc/\n- Join Linux communities\n\nHappy hacking! 🚀\n"
