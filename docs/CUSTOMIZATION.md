# smg4OS Customization Guide\n\nLearn how to customize smg4OS for your needs.\n\n## Kernel Customization\n\n### Modify Kernel Features\n\n```bash\ncd src/kernel\n./scripts/configure-kernel.sh\n```\n\nThis opens `menuconfig` for interactive configuration.\n\n### Common Options\n\n```\nGeneral Setup\n├── Kernel compression mode\n├── Kernel Command Line\n└── Processor type\n\nDevice Drivers\n├── Graphics\n├── Network adapters\n├── Storage controllers\n└── Input devices\n\nFilesystem\n├── ext4\n├── NTFS\n└── FAT\n```\n\n### Apply Custom Patches\n\n```bash\n# Create patch file\ncd src/kernel/linux\ngit diff > ../patches/custom.patch\n\n# Apply in future builds\necho \"patches/custom.patch\" >> ../patches/series\n```\n\n## Package Selection\n\n### Edit Package Lists\n\n```bash\n# View current packages\ncat packages/base.list\n\n# Edit base packages\nvim packages/base.list\n\n# Rebuild with new packages\n./scripts/build.sh packages\n```\n\n### Package Lists\n\n- `packages/base.list` - Always installed\n- `packages/desktop.list` - Desktop environment\n- `packages/gaming.list` - Gaming optimizations\n- `packages/dev.list` - Development tools\n\n### Adding Programs\n\n```bash\n# Add program to list\necho \"vlc\" >> packages/base.list\n\n# Rebuild\n./scripts/build.sh\n```\n\n## Desktop Customization\n\n### Change Desktop Environment\n\nEdit `config/desktop.conf`:\n\n```bash\n# Options: xfce, openbox, minimal\nDESKTOP_ENV=\"xfce\"\n\n# Theme\nDESKTOP_THEME=\"smg4-dark\"\n\n# Icons\nICON_THEME=\"papirus-smg4\"\n\n# Wallpaper\nWALLPAPER=\"/usr/share/pixmaps/smg4-wallpaper.png\"\n```\n\n### Install Custom Themes\n\nPlace theme files in:\n```\nconfig/themes/\n├── icons/\n├── gtk/\n├── wallpapers/\n└── fonts/\n```\n\n### Customize Boot Screen\n\n```bash\n# GRUB theme\nconfig/grub-theme/\n├── background.png\n├── theme.txt\n└── fonts/\n```\n\n## System Configuration\n\n### GRUB Settings\n\nEdit `config/grub.cfg`:\n\n```bash\nset default=0\nset timeout=5\nset theme=\"/boot/grub/themes/smg4/theme.txt\"\n```\n\n### Kernel Boot Parameters\n\nEdit `config/grub.cfg`:\n\n```bash\nlinux /boot/vmlinuz root=/dev/sda1 ro quiet splash\n```\n\nCommon parameters:\n- `quiet` - Suppress boot messages\n- `splash` - Show splash screen\n- `nosplash` - Hide splash screen\n- `nomodeset` - Disable graphics drivers\n- `debug` - Enable debug output\n\n### Hostname and Network\n\nEdit `config/hostname`:\n```\nsmg4-workstation\n```\n\nEdit `config/network/`:\n```\nAutomatic DHCP\nStatic IP configuration\nWiFi setup\n```\n\n## Performance Tuning\n\n### Disable Unused Services\n\n```bash\n# List services\nsystemctl list-unit-files\n\n# Disable service\nsudo systemctl disable service-name\n```\n\n### Swap Configuration\n\nEdit kernel boot parameters:\n```bash\nvm.swappiness=10\n```\n\n### I/O Scheduler\n\n```bash\n# Set I/O scheduler to cfg\necho \"cfg\" | tee /sys/block/sda/queue/scheduler\n```\n\n## Building Custom ISO\n\nWith all customizations:\n\n```bash\n./scripts/build-all.sh\n```\n\nCustom ISO output: `iso/smg4OS-custom.iso`\n\n## Testing Customizations\n\n```bash\n# Boot in QEMU\nqemu-system-x86_64 -cdrom iso/smg4OS-custom.iso -m 2G -enable-kvm\n```\n\n## Advanced Customization\n\n### Build Custom Kernel Module\n\n```bash\ncd src/kernel\nmake modules SUBDIRS=drivers/smg4/\n```\n\n### Create Custom Package\n\nSee [Package Guide](PACKAGES.md)\n\n### Modify Root Filesystem\n\n```bash\ncd build/rootfs\n# Edit files\ncd ..\n# Repack\ntar czf rootfs.tar.gz rootfs/\n```\n\n## Reverting Changes\n\n```bash\n# Restore defaults\ngit checkout config/\ngit checkout packages/\n\n# Clean build\n./scripts/clean.sh\n./scripts/build-all.sh\n```\n\nHappy customizing! 🎨\n"
