## Configuration

### Default Configuration Files

```
bob-player/
├── bob-player.sh          (Main player script)
├── tracks.conf            (Track database)
├── README.md              (This documentation)
├── .now_playing           (Current track info)
├── .bob_playlist          (Playlist data)
├── .bob_history           (Listening history)
└── .playlist_*            (Individual playlists)
```

### Tracks Configuration Format

The `tracks.conf` file uses a pipe-separated value format:

```
Song Title | Artist | Duration | Album | Year | BPM
```

**Example:**
```
MAMA LUIGI REMIX | Bob | 4:12 | Bob The Legendary | 2016 | 130
```

### Adding New Tracks

To add Bob's new tracks to the collection:

1. **Edit tracks.conf:**
   ```bash
   nano bob-player/tracks.conf
   ```

2. **Add a new line:**
   ```
   New Bob Song | Bob | 3:50 | Bob The Legendary | 2024 | 125
   ```

3. **Save and close**

4. **Restart Bob Player** to see the new track

### Track Properties Explained

- **Song Title**: The official title of the track
- **Artist**: Always "Bob" (or collaborative artists)
- **Duration**: MM:SS format (minutes:seconds)
- **Album**: Album the track is from
- **Year**: Release year
- **BPM**: Beats per minute (0 for skits)

## Troubleshooting

### Issue: Player won't start

**Solution:**
```bash
# Make sure the script is executable
chmod +x ./bob-player/bob-player.sh

# Run again
./bob-player/bob-player.sh
```

### Issue: Tracks not showing

**Solution:**
```bash
# Verify tracks.conf exists and has content
ls -la ./bob-player/tracks.conf
cat ./bob-player/tracks.conf

# If missing, recreate from installation
```

### Issue: Playlists not saving

**Solution:**
```bash
# Check write permissions in directory
ls -l ./bob-player/
chmod 755 ./bob-player/

# Clear corrupted playlist files
rm ./bob-player/.playlist_* 2>/dev/null || true
```

### Issue: History not tracking

**Solution:**
```bash
# Reset history file
rm ./bob-player/.bob_history 2>/dev/null || true
# History will be recreated on next play
```
