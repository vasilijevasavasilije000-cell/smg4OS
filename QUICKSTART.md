# 🚀 Quick Start Guide - smg4OS\n\nWelcome to smg4OS! Here's how to get started.\n\n## 📋 Prerequisites\n\n**System Requirements:**\n- Linux host (Ubuntu 20.04+ recommended)\n- 4GB RAM minimum\n- 20GB free disk space\n- POSIX shell\n\n**Required Tools:**\n```bash\nsudo apt-get install build-essential git curl wget bc bison flex \\\n    gcc g++ make grub-pc-bin grub-efi-amd64-bin xorriso mtools \\\n    dosfstools libncurses-dev libelf-dev libssl-dev\n```\n\n## 🎮 Your First Build\n\n### 1. Setup Development Environment\n\n```bash\ncd /workspaces/smg4OS\n./scripts/setup-dev.sh\n```\n\n### 2. Build the Complete System\n\n```bash\n./scripts/build-all.sh\n```\n\nThis will:\n1. Compile the Linux kernel\n2. Build userspace tools\n3. Create the root filesystem\n4. Generate a bootable ISO image\n\n**Time: ~30-60 minutes depending on hardware**\n\n### 3. Test the ISO\n\n```bash\n# Using QEMU (if installed)\nqemu-system-x86_64 \\\n    -cdrom iso/smg4OS-latest.iso \\\n    -m 2G \\\n    -smp 2 \\\n    -enable-kvm\n```\n\n### 4. Create Bootable USB (Optional)\n\n```bash\n# Identify USB device\nlsblk\n\n# Write ISO to USB (BE CAREFUL!)\nsudo dd if=iso/smg4OS-latest.iso of=/dev/sdX bs=4M\nsync\n```\n\n## 📁 Project Structure\n\n```\nsmg4OS/\n├── README.md                # Check build log: `cat build/build.log`\n2. Ensure prerequisites are installed\n3. Try: `./scripts/clean.sh` then rebuild\n\n### Out of Disk Space\n```bash\n./scripts/clean.sh\ndf -h  # Check available space\n```\n\n### Permission Errors\nSome steps need sudo:\n```bash\nsudo ./scripts/build.sh\n```\n\n## 🤝 Contributing\n\nWe'd love your help!
