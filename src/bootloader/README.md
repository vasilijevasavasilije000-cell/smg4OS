# smg4OS Bootloader Configuration\n\n## GRUB2 Setup\n\nThe bootloader configuration is handled by GRUB2 (Grand Unified Bootloader).\n\n## Configuration Files\n\n- `config/grub.cfg`: Main GRUB configuration\n- `config/grub-theme/`: Custom theme files (if used)\n\n## Boot Modes\n\nsmg4OS supports:\n- BIOS/Legacy boot\n- UEFI boot\n- Secure Boot (requires signing)\n\n## Boot Parameters\n\nCommon kernel boot parameters in GRUB:\n\n```\nlinux /boot/vmlinuz root=/dev/sda1 ro quiet splash\n```\n\n### Available Parameters\n\n- `quiet` - Suppress debug output\n- `splash` - Show splash screen\n- `nomodeset` - Disable graphics driver initialization\n- `debug` - Enable debug output\n- `vga=ask` - Ask for video mode\n- `single` - Single-user (recovery) mode\n- `mem=512M` - Limit available memory\n\n## Installation\n\nGRUB is installed to MBR or EFI partition during distro installation:\n\n```bash\n# Install to MBR\ngrub-install /dev/sda\n\n# Install to EFI\ngrub-install --target=x86_64-efi --efi-directory=/boot/efi /dev/sda\n\n# Update configuration\ngrub-mkconfig -o /boot/grub/grub.cfg\n```\n\n## Troubleshooting\n\nIf GRUB won't boot:\n1. Boot from live USB\n2. Mount root filesystem\n3. Reinstall GRUB\n4. Update configuration\n\n## Theming\n\nCustom GRUB theme can be added in:\n```\nconfig/grub-theme/\n├── background.png\n├── theme.txt\n└── fonts/\n```\n\nEnable in `/etc/default/grub`:\n```\nGRUB_THEME=\"/boot/grub/themes/smg4/theme.txt\"\n```\n"
