# smg4OS Kernel Build Notes\n\n## Default Configuration\n\nThe kernel.config file contains the baseline configuration for smg4OS.\n\n## Customization\n\nTo customize kernel configuration:\n\n```bash\ncd src/kernel\n./scripts/configure-kernel.sh\n```\n\nThis will open menuconfig for interactive configuration.\n\n## Patches\n\nPlace kernel patches in `patches/` directory:\n```\nsrc/kernel/patches/\n├── 0001-smg4-theme.patch\n├── 0002-performance.patch\n└── 0003-custom-drivers.patch\n```\n\nApply patches during build:\n```bash\ngit apply patches/*.patch\n```\n\n## Build Output\n\n- vmlinuz: Compressed kernel image\n- System.map: Kernel symbol map\n- vmlinux: Uncompressed kernel (for debugging)\n- Modules: Kernel modules in lib/modules/\n\n## Performance Tuning\n\nKey kernel options for smg4OS:\n- CONFIG_SMP=y - Multiprocessor support\n- CONFIG_HZ_1000=y - 1000Hz timer for responsiveness\n- CONFIG_PREEMPT=y - Preemptible kernel\n- CONFIG_CPU_FREQ=y - CPU frequency scaling\n- CONFIG_TRANSPARENT_HUGEPAGE=y - Memory optimization\n\n## Debugging\n\nFor kernel debugging, add debug symbols:\n```\nCONFIG_DEBUG_INFO=y\nCONFIG_DEBUG_KERNEL=y\nCONFIG_PRINTK=y\n```\n\nThen build with debug info.\n"
