# smg4OS Directory Structure Template\n# This defines the root filesystem layout\n\n/\n├── bin/                    # Essential user command binaries\n├── sbin/                   # Essential system binaries\n├── lib/                    # Essential shared libraries\n├── lib64/                  # 64-bit shared libraries\n├── usr/\n│   ├── bin/               # User command binaries\n│   ├── sbin/              # User system binaries\n│   ├── lib/               # User shared libraries\n│   ├── local/             # Local installation\n│   ├── share/             # Shared data\n│   │   ├── applications/  # Desktop entries\n│   │   ├── fonts/         # System fonts\n│   │   ├── pixmaps/       # Icons and images\n│   │   ├── man/           # Manual pages\n│   │   └── doc/           # Documentation\n│   └── src/               # Source code\n├── etc/                    # System configuration\n│   ├── default/           # Default configuration\n│   ├── init.d/            # Init scripts\n│   ├── systemd/           # systemd configuration\n│   ├── grub.d/            # GRUB configuration\n│   ├── network/           # Network configuration\n│   ├── security/          # Security configuration\n│   └── ssl/               # SSL certificates\n├── boot/\n│   ├── grub/              # GRUB bootloader\n│   ├── vmlinuz            # Kernel image\n│   ├── initrd.img         # Initial ramdisk\n│   └── efi/               # UEFI bootloader (if applicable)\n├── var/\n│   ├── log/               # Log files\n│   ├── lib/               # Variable data\n│   ├── tmp/               # Temporary files\n│   ├── cache/             # Cache directory\n│   ├── spool/             # Spool directory\n│   └── run/               # Runtime data (symlink to /run)\n├── home/                   # User home directories\n│   └── username/          # Individual user homes\n├── root/                   # Root user home\n├── tmp/                    # Temporary files (world-writable)\n├── dev/                    # Device files\n├── proc/                   # Process information\n├── sys/                    # System information\n├── run/                    # Runtime data\n├── opt/                    # Optional software\n├── srv/                    # Service data\n├── media/                  # Mount points for removable media\n├── mnt/                    # Mount points for filesystems\n└── lost+found/             # Recovery directory\n\nKey Points:\n- /bin, /sbin, /lib: Essential binaries and libraries\n- /usr: User programs and data\n- /etc: Configuration files\n- /var: Variable data (logs, caches, temp)\n- /home: User home directories\n- /root: Root user home\n- /tmp: Temporary files\n- /dev: Device files\n- /proc, /sys: Virtual filesystems\n\nSmg4OS specific:\n- /usr/share/pixmaps/smg4-logo.png: SMG4 branding\n- /usr/share/backgrounds/: SMG4 wallpapers\n- /etc/smg4/: SMG4-specific configuration\n- /opt/smg4games/: Gaming optimizations\n"
